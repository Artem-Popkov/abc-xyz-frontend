# Формат входных файлов

Формат кейса 12 и программы бэкенда. Нужны два файла. Их можно перетащить на экран «Данные» вместе или по одному: какой файл какой, сайт определяет по заголовку.

Пример: `docs/sample/items.csv` (150 товаров) и `docs/sample/sales.csv` (5855 строк продаж за 2025 год). Те же файлы можно скачать на экране «Данные».

## items.csv — справочник товаров

| Колонка | Обязательна | Пример |
|---------|-------------|--------|
| `item_code` | да | `P001` |
| `name` | нет (если нет — показываем код) | `Молоко 3,2% 1 л` |
| `category` | нет | `Молочные продукты` |

## sales.csv — продажи по чекам

| Колонка | Формат | Пример |
|---------|--------|--------|
| `doc_id` | номер чека | `CHK-00001` |
| `date` | `ГГГГ-ММ-ДД` | `2025-03-14` |
| `item_code` | код из items.csv | `P001` |
| `qty` | число > 0 | `6` |
| `price` | число ≥ 0, цена за единицу | `137.46` |

## Общие правила

- Разделитель `,` или `;` (выбирается тот, которого больше в заголовке). Кодировка UTF-8, BOM допускается.
- Поле с разделителем берётся в кавычки: `"Молоко 3,2% 1 л"`. Кавычка внутри поля — две кавычки `""`.
- Порядок колонок любой, регистр заголовка не важен.
- В числах допускается десятичная запятая (`137,46`).

## Проверки

Как в программе бэкенда: строка с ошибкой **пропускается**, остальные идут в расчёт. Список пропущенных строк с причинами показывается на экране. У строки проверяется первая найденная ошибка, в таком порядке:

**items.csv**
1. Нет колонки `item_code` → файл не принимается.
2. Пустой `item_code` → строка пропускается.
3. Повтор `item_code` → пропускается (остаётся первая строка).
4. Не осталось ни одного товара → файл не принимается.

**sales.csv**
1. Нет одной из колонок `doc_id, date, item_code, qty, price` → файл не принимается.
2. Число полей в строке не совпадает с заголовком.
3. Дата не в формате `ГГГГ-ММ-ДД` или такой даты нет (`2025-02-30`).
4. Дата в будущем.
5. `qty` не число или `qty ≤ 0`.
6. `price` не число или `price < 0`.
7. Товара нет в items.csv.
8. Повтор тройки `(doc_id, item_code, date)`.
9. Не осталось ни одной продажи → файл не принимается.

Продажи проверяются по справочнику, поэтому статус «Продажи» появляется, когда загружен корректный items.csv. Повторная загрузка файла заменяет старый, а не дописывает к нему (требование кейса «повторная загрузка не дублирует данные»).
